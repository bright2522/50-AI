# 50-AI

ให้ "AI 50 บุคลิก" ที่แตกต่างกัน — เด็ก วัยรุ่น ผู้ใหญ่ ผู้สูงอายุ ผู้พิการ (ตาบอด หูหนวก เคลื่อนไหวลำบาก)
และผู้ป่วยโรคเรื้อรัง (เบาหวาน มะเร็ง หัวใจ ไมเกรน ฯลฯ) — ช่วยทดลองใช้เว็บไซต์หรือแอปของคุณ
แล้วเขียน feedback กลับมาในมุมมองของแต่ละคน เพื่อช่วยตรวจสอบการเข้าถึง (accessibility) และประสบการณ์ใช้งานที่หลากหลาย

## โครงสร้างโปรเจกต์

- [`personas.json`](personas.json) — ข้อมูลบุคลิก AI ทั้ง 50 ตัว (ชื่อ, กลุ่ม, เงื่อนไขร่างกาย, สิ่งที่ให้ความสำคัญ)
- [`index.html`](index.html) + [`app.js`](app.js) + [`personas.js`](personas.js) — เว็บหน้าเดียวที่โชว์บุคลิกทั้งหมด,
  มีดีโมให้ทดลองเรียก AI จริงจากเบราว์เซอร์ (ต้องใช้ Anthropic API key ของคุณเอง) และโชว์ซอร์สโค้ดเครื่องมือหลักให้ก็อปไปใช้ได้ทันที
- [`engine/persona-review.mjs`](engine/persona-review.mjs) — สคริปต์ Node.js ตัวเต็ม ใช้ Playwright เปิดเว็บไซต์เป้าหมายจริง
  (จำลองมือถือ, ตรวจ alt text / ปุ่มไม่มี label / ปุ่มเล็กเกินมาตรฐานอัตโนมัติ) แล้วให้ Claude เขียน feedback ในมุมมองของทั้ง 50 บุคลิก

## วิธีดูหน้าเว็บ

เปิดผ่านเว็บเซิร์ฟเวอร์ (ไม่ใช่ดับเบิลคลิกไฟล์ตรงๆ เพราะเบราว์เซอร์บล็อกการโหลดไฟล์ข้ามกันแบบ `file://`):

```bash
npx serve .
```

หรือเปิดผ่าน GitHub Pages หลัง push ขึ้น repo แล้วเปิด Settings → Pages → Deploy from branch `main` / root

## วิธีรันเครื่องมือหลักแบบเต็ม (option 2) บนเครื่องตัวเอง

```bash
cd engine
npm install
npx playwright install chromium

# Windows (PowerShell)
$env:ANTHROPIC_API_KEY="sk-ant-..."
# macOS/Linux
export ANTHROPIC_API_KEY="sk-ant-..."

node persona-review.mjs https://your-site.com
```

ผลลัพธ์จะถูกบันทึกไว้ที่ `engine/reports/<โดเมน>-<เวลา>.md` และ `.json` เป็น feedback จาก AI ทั้ง 50 บุคลิก

## หมายเหตุเรื่องความปลอดภัย

ดีโมบนหน้าเว็บเรียก Claude API ตรงจากเบราว์เซอร์ของผู้ใช้ด้วยคีย์ของผู้ใช้เอง คีย์จะถูกเก็บไว้ในหน่วยความจำของเบราว์เซอร์
ระหว่างใช้งานหน้านั้นเท่านั้น ไม่ถูกส่งไปที่เซิร์ฟเวอร์อื่นใดนอกจาก `api.anthropic.com` — เหมาะสำหรับทดลอง/สาธิตเท่านั้น
ไม่แนะนำให้ใช้คีย์การใช้งานจริง (production key) กับหน้าเว็บสาธารณะ
