ให้ผู้ใช้ 50 แบบ ช่วยลองเว็บของคุณ

ตั้งแต่เด็ก ผู้สูงอายุ ผู้พิการ ผู้ป่วย คนทั่วไป ไปจนถึงผู้เชี่ยวชาญ ทุกคนลองใช้แล้วบอกว่าเจอปัญหาอะไร

เลือกบุคลิก ดูโค้ด

1. เลือกผู้ทดสอบ

คลิกการ์ดเพื่อเลือก แนะนำ 3–6 ตัวต่อครั้ง

เลือกแล้ว 0 ตัว ไปขั้นต่อไป →

2. ให้ AI ลองใช้

ใส่ข้อมูลเว็บของคุณ แล้วกดเริ่ม

1

เว็บไซต์ที่จะทดสอบ

เบราว์เซอร์โหลดเว็บข้ามโดเมนไม่ได้ กรุณาวางข้อความหรืออธิบายหน้าเว็บด้านล่าง

2

ผู้ทดสอบที่เลือก

3

Anthropic API key ของคุณ

ใช้เฉพาะในเบราว์เซอร์นี้ ไม่ถูกบันทึกหรือส่งไปที่อื่นนอกจาก api.anthropic.com

3. โค้ดสำหรับรันเอง

เวอร์ชันเต็มเปิดเว็บจริงด้วย Playwright แล้วให้ทั้ง 50 บุคลิกรีวิว ก็อปไปใช้ได้เลย

วิธีรัน 4 ขั้นตอน
  1. วางไฟล์ทั้งสามในโฟลเดอร์เดียวกัน แล้วรัน npm install
  2. รัน npx playwright install chromium
  3. ตั้งค่า ANTHROPIC_API_KEY
  4. รัน node persona-review.mjs https://your-site.com ผลลัพธ์อยู่ในโฟลเดอร์ reports/
