🧑‍🤝‍🧑 50-AI

ให้ "AI 50 บุคลิก" — เด็ก ผู้สูงอายุ ผู้ใหญ่ ผู้พิการ (ตาบอด หูหนวก) และผู้ป่วยโรคเรื้อรัง (เบาหวาน มะเร็ง ฯลฯ) — ช่วยทดลองใช้เว็บไซต์หรือแอปของคุณ แล้วคอมเมนต์ feedback กลับมาในมุมมองของแต่ละคน

50 personas เปิดเว็บจริงด้วย Playwright วิเคราะห์ด้วย Claude โค้ดก็อปใช้ได้ทันที

บุคลิก AI ทั้ง 50 ตัว

แต่ละตัวมีเงื่อนไขร่างกาย/สถานการณ์ต่างกัน จึงมองเห็นปัญหาการใช้งานคนละมุม

ลองให้ AI ทดสอบจริง

วางลิงก์เว็บไซต์ + สรุปเนื้อหา/สิ่งที่อยู่บนหน้านั้น (เนื่องจากเบราว์เซอร์ไม่สามารถโหลดเนื้อหาข้ามโดเมนได้โดยตรง) แล้วเลือกบุคลิกที่อยากให้ช่วยรีวิว ระบบจะเรียก Claude API ตรงจากเบราว์เซอร์ของคุณด้วย API key ของคุณเอง (คีย์จะถูกเก็บไว้ในเครื่องคุณเท่านั้น ไม่ถูกส่งไปที่เซิร์ฟเวอร์อื่นใด)

รับคีย์ได้ที่ console.anthropic.com — ใช้เพื่อทดสอบเท่านั้น ระบบไม่บันทึกคีย์ของคุณไว้ที่ใด

โค้ดเบื้องหลัง (ก็อปไปใช้ได้เลย)

เวอร์ชันเต็มที่ใช้ในดีโมนี้เปิดเว็บไซต์จริงด้วย Playwright (จำลองมือถือ ตรวจ alt text / ปุ่มไม่มี label / ปุ่มเล็กเกินไปอัตโนมัติ) แล้วส่งให้ Claude เขียน feedback ในมุมมองของแต่ละบุคลิกทั้ง 50 ตัว รันบนเครื่องของคุณเองได้ทันที

วิธีรันบนเครื่องตัวเอง:
  1. สร้างโฟลเดอร์โปรเจกต์ ก็อปไฟล์ทั้ง 3 ด้านบนลงไป (personas.json ต้องมีครบ 50 ตัว ดูตัวเต็มได้ใน repo)
  2. รัน npm install แล้ว npx playwright install chromium
  3. ตั้งค่า ANTHROPIC_API_KEY เป็นคีย์ของคุณ
  4. รัน node persona-review.mjs https://your-site.com
  5. ผลลัพธ์ feedback ทั้ง 50 บุคลิกจะถูกบันทึกเป็นไฟล์ .md และ .json ในโฟลเดอร์ reports/
50-AI — โปรเจกต์เพื่อทดสอบการเข้าถึง (accessibility) และประสบการณ์ผู้ใช้ที่หลากหลาย
